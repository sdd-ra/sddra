# 10. Sənin dediyin `~` məsələsi də `.sdd` protocol-un hissəsi olmalıdır

Məsələn:

```text
~ = progress / active
+ = done
- = failed
! = blocked
? = decision/input required
> = next
@ = reference
# = rule
```

Məsələn:

```text
Payment

BE +
FE +
MD ~
QA ?
DO -
VERIFY -
```
