# 19.14. Alert ≠ Incident

Bu distinction vacibdir.

```text
Alert
```

deyir:

> Şübhəli vəziyyət var.

```text
Incident
```

deyir:

> Real business/system impact təsdiqlənib.

Məsələn:

```text
CPU 90%
```

alert-dir.

Amma:

```text
API unavailable
```

incident-dir.

