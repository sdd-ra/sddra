# PHASE 126 — `AI ORCHESTRATION & SKILL GRAPH`

İndi əvvəl qurduğumuz bütün hissələri bir-birinə bağlayan qat gəlir.

Əsas fikir:

> **AI task üçün skill siyahısı seçməməlidir; task-ın vəziyyətinə görə hansı skill-in növbəti işləməli olduğunu müəyyən etməlidir.**

# 46. Növbəti böyük problem artıq görünür

İndi sistem çox ağıllıdır, amma bir risk yaranır:

> **Knowledge və skill-lər zaman keçdikcə çoxalacaq. Hansının doğru, hansının köhnə, hansının project-specific, hansının generic olduğunu necə idarə edəcəyik?**

Burada artıq sadə `versioning` kifayət deyil.

Növbəti mərhələni mən belə qurardım:

# **PHASE 127 — `KNOWLEDGE LIFECYCLE & TRUTH SYSTEM`**

Burada:

```text
OBSERVED
→ CANDIDATE
→ VALIDATED
→ ESTABLISHED
→ PREFERRED
→ DEPRECATED
→ SUPERSEDED
→ ARCHIVED
```

kimi **knowledge truth lifecycle** quracağıq.

Ən maraqlısı isə `TRUST SCORE + EVIDENCE + SOURCE + SCOPE + RECENCY + USAGE + CONFLICT` birlikdə işləyəcək.

Beləliklə AI sadəcə:

> "Məndə bu knowledge var."

deməyəcək.

Deyə biləcək:

> **"Bu knowledge nə qədər doğrudur, hansı evidence-a əsaslanır, harada keçərlidir və hansı knowledge tərəfindən əvəz olunub."**
