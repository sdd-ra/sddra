# PHASE 127 — `KNOWLEDGE LIFECYCLE & TRUTH SYSTEM`

Burada `.sdd` sisteminin ən güclü tərəflərindən birini qururuq:

> **AI hər öyrəndiyi şeyi "doğru" kimi qəbul etməməlidir.**

Çünki AI həm koddan, həm insan qərarlarından, həm internetdən, həm də öz analizindən knowledge toplayacaq.

Bunların hamısının etibarlılığı eyni deyil.

# 47. Amma burada yeni təhlükə yaranır

Sistem artıq knowledge öyrənir.

Decision saxlayır.

Bunlar zamanla **çoxalacaq**.

Əgər hər şey saxlanılırsa:

```text
100 tasks
→ 500 knowledge

1,000 tasks
→ 5,000 knowledge

10,000 tasks
→ 50,000 knowledge
```

və AI yenə hamısını oxumamalıdır.

Ona görə növbəti mərhələ:

# **PHASE 128 — `KNOWLEDGE INDEX & CONTEXT COMPILER`**

Burada `.sdd` üçün əsl **AI retrieval engine** quracağıq:

```text
Human:
    "Implement refund"

        ↓

Intent Compiler

        ↓

Task Graph

        ↓

Knowledge Index

        ↓

Semantic Search
        +
Scope Filter
        +
Truth Filter
        +
Authority Filter
        +
Version Filter
        +
Dependency Filter

        ↓

Minimal Relevant Context

        ↓

AI
```

Ən vacib prinsip isə:

> **AI-yə mümkün qədər çox knowledge vermək yox, düzgün anda mümkün qədər az, amma düzgün knowledge vermək.**

Bu mərhələ `.sdd`-nin **context-window efficient brain** hissəsi olacaq.
