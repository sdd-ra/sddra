# PHASE 132 — `MULTI-AGENT COORDINATION & SHARED ENGINEERING STATE`

Burada `.sdd` sistemini daha bir pillə böyüdürük:

> **Bir AI agent kod yazır, digəri araşdırır, digəri test edir, digəri review edir — amma hamısı eyni Engineering State üzərində işləyir.**

Əsas məqsəd: agentlərin bir-birinin işini pozmaması və hər agentin **nə baş verdiyini, nə edilməli olduğunu və nəyə toxuna biləcəyini** anlaması.

---

## 1. Agent ≠ Owner

Əvvəlcə vacib distinction:

```text
Agent
    = işi görən

Owner
    = həmin sahəyə cavabdeh olan

Authority
    = dəyişiklik etmək hüququ olan
```

Məsələn:

```text
Agent-A
    role: backend

Owner:
    Payment Domain

Authority:
    implementation = allowed
    architecture = review required
```

Növbəti mərhələdə daha fundamental bir məsələni həll etmək lazımdır:
