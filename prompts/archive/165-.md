# PHASE 106 — CONTEXT ENGINE & KNOWLEDGE RESOLUTION

Bu dərsdə `.sdd` sisteminin **Context Engine** hissəsini qururuq.

Əvvəlki dərsdə belə bir model yaratmışdıq:

```text
TASK
 ↓
AGENT
 ↓
SKILL
 ↓
TOOLS
```

Amma burada böyük problem yaranır:

> **Agent task-ı icra etmək üçün hansı məlumatları oxumalıdır?**

Böyük project-də agentə bütün repository-ni və bütün `.sdd`-ni vermək düzgün deyil.

---

# 106.1. Context nədir?

Context:

> Agent-in konkret task-ı düzgün icra etməsi üçün həmin anda ehtiyac duyduğu relevant məlumatlar toplusudur.

Məsələn:

```text
TASK:
Implement POST /auth/login
```

Agentə bütün project lazım deyil.

Lazım ola bilər:

```text
API specification
Auth domain
User model
Token rules
Authentication architecture
Existing login service
Relevant tests
Coding policy
```

---

# 106.2. Context ≠ Knowledge Base

Knowledge Base:

```text
bütün məlumatlar
```

Context:

```text
bu task üçün seçilmiş məlumatlar
```

Model:

```text
Knowledge
   │
   ▼
Context Resolver
   │
   ▼
Relevant Context
   │
   ▼
Agent
```

---

# 106.8. Context Ranking

Resolver hər artifact üçün score hesablaya bilər:

```text
relevance
+
dependency
+
scope
+
recency
+
priority
```

Məsələn:

```text
auth/login.go
→ 0.98

auth/register.go
→ 0.71

payment/service.go
→ 0.03
```

Token budget çatmırsa aşağı score-lu context çıxarılır.

---

# 106.9. Relevance ≠ Similarity

Çox vacib.

Bir fayl semantic olaraq task-a oxşaya bilər, amma dependency olmaya bilər.

Məsələn:

```text
payment/login.go
```

və:

```text
auth/login.go
```

semantic olaraq oxşardır.

Amma task:

```text
auth login
```

üçündür.

Ona görə yalnız vector similarity kifayət deyil.

---

# 106.29. Context Expansion ≠ Scope Expansion

Çox vacib fərq.

Context expansion:

> əlavə məlumat oxumaq.

Scope expansion:

> əlavə fayla/ressursa dəyişiklik etmək.

Məsələn:

```text
read user/profile.go
```

context expansion ola bilər.

```text
modify user/profile.go
```

scope expansion ola bilər.

---

# 106.30. Read Scope və Write Scope

Bu iki scope ayrılmalıdır.

```text

  auth/**
  user/model.go

write_scope:
  auth/**
```

Agent user modelini oxuya bilər, amma dəyişə bilməz.

Bu çox güclü security modelidir.

# 106.47. Context Resolver Algorithm

Conceptual olaraq:

```text
resolve(task):

1. Load task
2. Load required skill
3. Read context contract
4. Resolve task dependencies
5. Traverse knowledge graph
6. Find relevant artifacts
7. Check permissions
8. Remove sensitive data
9. Rank candidates
10. Apply token budget
11. Validate required context
12. Create snapshot
13. Return context
```
