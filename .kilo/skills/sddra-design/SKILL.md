# SDDRA Design Skills

Source of truth: `.sdd/skills/design/` — this skill is the routing
wrapper. Read `.sdd/skills/design/INDEX.sdd` before applying.

## What it covers

- **Taste evaluation** (taste-evaluation.sdd): judging design output
  against taste criteria before shipping.
- **Design heuristics** (design-heuristics.sdd): reusable heuristics
  for layout, hierarchy, spacing, and typography decisions.
- **Visual design** (visual-design.sdd) and **web design guidelines**
  (web-design-guidelines/): visual quality bars for web surfaces.
- **UX patterns** (ux-patterns.sdd): interaction pattern catalog.
- **Accessibility** (accessibility.sdd): a11y requirements and checks.
- **Design system** (design-system.sdd): token and component system rules.
- **Design review** (design-review.sdd): structured review flow.

Imported curated skill packages live under design/imported/ and
meta/imported/ — per CLAUDE.md import rules ([SK6] lifecycle).

## When to use

Use for any UI/UX/visual task: evaluation before approval, heuristics
before creation, a11y before shipping. Read the named spec first.
