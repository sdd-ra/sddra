# SDD AI Engineering System

Clean-project SDD skeleton.

Separation:
- Source code = real implementation
- `.sdd/` = compact AI operational model
- `docs/` = human-readable project knowledge

Core workflow:
Prompt → Discovery → Architecture Profile → Skills → Project Model → Task → Chain → Implementation → QA → DO (if required) → VR

Architecture is selected from evidence. The system avoids automatic microservices/Kubernetes/etc. without requirements.
