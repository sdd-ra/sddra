# .sdd/decisions/

Architecture-level decisions — either approved from a proposal or flagged
by the Prompt Intelligence Layer (`.sdd/prompts/prompts.sdd` -> Decision:
ESCALATE, [P20]) as a candidate "NEW ARCHITECTURE DECISION".

A decision entry is only created here after explicit human confirmation
(see `.sdd/PROJECT.sdd` -> HumanDecision, Rules [R9]/[R11] — this file does
not restate that rule, it just applies it to architecture decisions).

Status: no decisions recorded yet in this replay.

The lifecycle mechanics (states, rules `[D1]`-`[D17]`, the
`project/<domain>/decisions/<state>/*.sdd` storage convention) live in
`decisions.sdd` in this same directory — this README stays a short
human-facing summary and does not restate that engine.
