# SDDRA LLM Layer

Generated by `/sdd-llm --export` from canonical `.sdd/`. **Do not hand-edit**
generated files — regenerate with the command instead.

## Purpose

This layer exists so an LLM (or RAG pipeline) can reason over the entire SDDRA
corpus as if it were a built-in expert. It provides:

- A standards-compliant `llms.txt` entry point
- A concatenated, readable `llms-full.txt` for one-shot context loads
- Machine-normalized JSON/JSONL views of the knowledge graph
- Boundary-based chunks (per spec section) ready for embedding
- Per-goal context packs that stay under a few thousand tokens

## Principles

1. **Single source of truth** — `llm/` is derived from `.sdd/`. Never edit it by hand.
2. **Deterministic** — generation is a pure function of `.sdd/` contents.
3. **Minimal slices** — each artifact answers one kind of question.
4. **Traceable** — every record preserves file path, line range, and `@references`.
5. **Stable IDs** — reuse graph IDs (TASK-, DEC-, REQ-, etc.).
6. **Boundary chunking** — chunks follow spec sections (Purpose, Rules, Flow),
   not arbitrary token counts.
7. **Human + machine readable** — Markdown for humans, JSON/JSONL for tools.

## Consumption patterns

| Question | Artifact |
|---|---|
| Minimal context to run `/sdd-plan` | `context-pack.json` → `command-map.json` |
| Blocking rules for X | `rules.json` + `chunks/` rule section |
| Blast radius of TASK-123 | `graph.json` / `relations.jsonl` (reverse traversal) |
| Explain DL2 flow in plain English | `chain-map.json` + `chunks/` chain section |
| Which skills apply to feature Y | `skill-map.json` |
| Full corpus in one read | `llms-full.txt` |

## Artifacts

| File | Format | Purpose |
|---|---|---|
| `llms.txt` | Markdown (llmstxt.org) | Minimal entry for LLMs |
| `llms-full.txt` | Markdown | Concatenated essential specs |
| `INDEX.md` | Markdown | Human+LLM readable map |
| `context-pack.json` | JSON | Machine index for tools/agents |
| `entities.jsonl` | JSONL | Graph entities |
| `relations.jsonl` | JSONL | Graph relations |
| `graph.json` | JSON | Compact graph view |
| `chain-map.json` | JSON | Chains/arms/stages |
| `command-map.json` | JSON | Commands + usage + rules |
| `skill-map.json` | JSON | Skills L1–L5 |
| `rules.json` | JSON | Extracted RXX rules |
| `decisions.jsonl` | JSONL | Decisions summary |
| `tasks.jsonl` | JSONL | Tasks summary |
| `chunks/` | `.md` + `.json` per chunk | Embedding-ready chunks |
